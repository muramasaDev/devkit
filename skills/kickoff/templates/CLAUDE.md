## 작업 규칙
- 커밋과 push 는 요청이 있을 때만 한다
- 비밀번호, API 키, 토큰은 코드와 Git 에 넣지 않는다 (`.env` 는 `.gitignore` 에 있음)
- 화면 작업은 `uiuxpatterns` 스킬을 따른다 (설계 전 모드 A, 구현 후 모드 C)
- 로그인, 업로드, DB, API, 의존성, 관리자 화면, 결제, 쿠폰, 인증번호, AI 기능 작업은 `securecoding` 스킬을 따른다
- 첫 기능 코드 전에 `docs/security/security-architecture.md` 를 채운다 (역할, 경로 구분, 값의 계산 위치, 비밀 보관)
- 가격, 수량, 쿠폰, 결제 성공, 권한 값은 클라이언트가 보낸 값을 쓰지 않고 서버가 정한다
- 보안 점검 결과는 `docs/security/security-report.md` 에 남긴다. 실행하지 않은 시험은 `NOT_TESTED`
