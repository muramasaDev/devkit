# Defaults (기본값 정본 표)

- 역할: 패턴 파일이 `제품에서 정한다` 로 남기던 값을 이 표에서 한 번에 정한다. 값을 정해 달라는 요청이 오면 이 표의 기본값을 바로 쓴다
- 쓰는 법: 패턴 파일의 `DF-nn` 은 이 표의 행을 가리킨다. 바꿔도 되는 조건에 해당할 때만 다른 값을 쓰고, 바꾼 값 및 이유를 설계 문서에 한 줄 적는다
- 근거 표기: `확인` 원문을 읽음, `요지` 요약본에서만 확인, `일반 권고, 출처 미확인` 출처를 읽지 못한 일반 UX 권고. 일반 권고의 수치는 측정으로 바꿀 수 있는 임시 기본값이다
- 읽은 원문 (2026-11-25): Nielsen Norman Group 응답 시간 3단계 한계, WCAG 2.2 Understanding 문서 (2.2.1, 2.2.2, 4.1.3), Material Web 모션 토큰 파일 (`_md-sys-motion.scss` v0_192), Apple UIKit `UILongPressGestureRecognizer.minimumPressDuration`, Android `ViewConfiguration` 및 `PullToRefreshDefaults` 참조 문서, WAI-ARIA APG 스위치 패턴, Chrome modern-web-guidance 지침 (motion, persistent-toast-notifications, switch, ime-safe-enter-submit, dialog)
- Material 3 스낵바 및 뱃지 명세, Material 2 스낵바 문서는 스크립트 렌더링 페이지라 본문을 읽지 못했다. 해당 수치는 일반 권고로 둔다
