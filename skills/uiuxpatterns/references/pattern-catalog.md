# Pattern Catalog (90개 패턴 색인 및 원본 이미지 참조 관계)

- 역할: 90개 패턴의 ID, 원본 명칭, 상세 파일, 참조 이미지를 한 곳에서 찾는 색인
- 상세 명세(18개 항목)는 카테고리별 파일에 있음. 필요한 카테고리 파일만 연다
- 명칭 출처: 카테고리 02 를 제외한 81개는 원본 이미지 카드에 적힌 한국어 및 영어 명칭 그대로. 카테고리 02 의 9개는 우디디자인랩 UI 미니 사전 (https://woodydesignlab.com/ui/dict) 입력 폼 탭의 명칭을 2026-11-23 에 대조해 맞춤 (색인: `woody-dict-index.csv`)
- 장면 열: 이미지 카드에 실제로 보이는 내용만 기록. 원본이 움직이는 화면의 캡처라서 일부 카드는 동작 중간 장면임

## 패턴 추가 방법

1. 해당 카테고리 파일에 18개 항목 형식으로 패턴을 추가하고 ID 는 접두 뒤 다음 번호를 쓴다
2. 이 파일의 해당 표에 한 줄을 추가한다
3. 새 카테고리는 `references/` 에 파일을 만들고 위 `카테고리 및 파일` 표와 `SKILL.md` 의 참조 표에 한 줄씩 추가한다
4. 저장소에서 `npm test` 로 개수 및 항목 누락을 확인한다
