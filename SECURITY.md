# Security Policy

## Scope
This repository holds Markdown skills, templates and one validation script (`scripts/validate_uiuxpatterns.py`). It runs no network code. Security reports can cover: wrong or unsafe guidance in a skill, a script defect, or sensitive data committed by mistake.

## Report
Use GitHub private vulnerability reporting: Security tab > Report a vulnerability. Do not open a public issue for sensitive data or an exploitable defect.
Expect a first reply within 7 days.

## Wrong guidance
A rule that is factually wrong or outdated is a normal issue. Include the file, the claim, and a source.
